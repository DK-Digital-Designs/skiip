# Support Issues

Read this when you need the issue-reporting and triage process from [Operations](../OPERATIONS.md).

Customer and vendor entry points:

- buyers and sellers can use **Report an issue** from their account menu
- buyers can also use **Issue with your order** in the footer or report against an item in My Orders/order tracking
- submissions are authenticated; buyers and vendors receive a case reference and are contacted externally

Admin process:

1. Monitor **Admin Issues** for `open` and high-priority cases during the pilot.
2. Review linked order/vendor information and record internal notes.
3. Set status to `in_review` while investigating, then `resolved` or `closed` after communication/action.
4. Use the linked refund action only after refund approval; a submitted case never automatically moves money.

Priority handling:

- refund requests and paid vendor cancellations start as `high`
- other buyer/vendor submissions start as `normal`, with admin escalation to `high` or `urgent` as needed
- a paid vendor cancellation means refund review is required; cancelled status alone is not proof of a completed refund
