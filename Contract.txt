2.	Project Details
●	Description:
●	Skiip is a mobile-first web application designed to enable festival attendees to browse vendors’ menus, place orders online, and collect their purchases without waiting in queues. The platform provides a streamlined, QR-code accessible ordering experience that improves service efficiency, increases vendor sales, and enhances the attendee experience.
●	The platform consists of three main user interfaces: 	
Customer Ordering Interface — A responsive web interface that allows festival attendees to select a vendor, browse real-time menus, add items to a cart, submit orders, and receive updates and notifications via WhatsApp or SMS.                    Vendor Dashboard — A secure, real-time order management panel where vendors can view new orders, update order statuses (e.g., New, In Prep, Ready), and manage fulfilment for service points at events. 				                   Admin/Organiser Console — A management interface for event organisers to onboard vendors, configure menus, view orders by vendor and status, monitor transaction volume, and generate simple analytics.

●	The platform will integrate online payment processing (Stripe) for secure card payments and automated revenue settlement, and WhatsApp notifications for real-time order confirmations and status updates. The system will be built using modern scalable web technologies, ensuring fast performance during high-concurrency traffic typical at live events.

3.	Technical Specifications
●	Technical Overview:
●	The Skiip platform will be developed as a responsive, web-based ordering system designed for high-traffic event environments. The solution will leverage modern web technologies to ensure scalability, performance, and ease of future expansion. The system will consist of a customer-facing ordering interface, a vendor management interface, and an administrative backend. Version control will be managed using GitHub, and development will follow modular, maintainable coding practices.
●	System Design & Functionality:
●	Frontend:
The front-end will be built as a responsive web application optimised for mobile-first usage, designed to the client specification. It will include customer-facing views such as vendor listings, vendor menus, item selection, cart and order summary screens, and order status notifications. The vendor-facing interface will include order dashboards, order detail views, and manual order status update controls. The user interface will prioritise speed, clarity, minimal user friction, suitable for use in live event environments.
●	Backend:
The backend will manage all server-side logic, including user and vendor data handling, menu and item management, order creation and processing, and order status tracking. A structured database will be used to store customer details, vendor profiles, menus, orders, and order statuses. The system will be designed to support concurrent users and allow for future enhancements such as analytics, payment processing, and advanced reporting.
●	APIs and Integrations: 
●	The platform may integrate with third-party services to enhance functionality, including payment gateways (e.g. Stripe), messaging services (e.g. WhatsApp Business API for order confirmations and status notifications), and hosting or cloud infrastructure providers. All integrations will be implemented using secure, documented APIs and will be modular to allow replacement or upgrades as required.
●	Security Measures:
●	The platform will implement standard web security best practices to protect user and vendor data. These measures include secure HTTPS communication via SSL/TLS encryption, role-based authentication for administrators and vendors, secure handling of user input to prevent common vulnerabilities, and restricted access to sensitive system functions. Where third-party payment gateways are used, all payment data will be handled directly by the gateway to minimise PCI compliance exposure for the platform.
 
4.	Scope of Work
●	Overall Tasks:
●	A general overview of tasks, activities, and responsibilities that the Developer will undertake during the project's lifecycle.
●	Task Breakdown:
●	Front-end Development: Design and development of the customer-facing and vendor-facing user interfaces based on the approved Skiip demo. This includes the vendor listing screen, individual vendor pages with their respective menus, product/item display, cart functionality, order summary screens, and basic order status views. The interface will be fully branded, intuitive, and responsive across desktop and mobile devices, ensuring smooth navigation and a clear ordering experience.
●	Back-end Development: Development of the core system logic to support online ordering functionality. This includes vendor management, menu and item management, order creation and storage, order status handling (including manual order status updates by vendors), and basic customer and vendor data management. The backend will support secure interactions between users, vendors, and the system, and allow for future integration of payment gateways and messaging tools.
●	CMS/Admin & Vendor Panel Integration: Implementation of an admin and vendor management system that allows administrators to manage vendors and platform content, and allows vendors to manage their own profiles, menus, pricing, and availability. Vendors will be able to view incoming orders and manually update order statuses (e.g. received, preparing, completed). The CMS/admin panel will also support basic content updates such as text, images, and vendor listings.
●	SEO Optimization: Implementation of foundational SEO practices tailored to the Skiip platform, including search-engine-friendly page structures for vendor listings and menus, metadata setup for core pages, mobile optimisation, performance optimisation, and clean URLs to support discoverability and future marketing efforts.
●	Quality Assurance: End-to-end testing of the Skiip platform to ensure that customer ordering flows, vendor dashboards, and admin controls function correctly. This includes testing across major browsers and devices, validating order placement and status updates, checking responsiveness and performance under normal usage, fixing identified bugs, and ensuring the system meets the agreed MVP requirements prior to deployment.
